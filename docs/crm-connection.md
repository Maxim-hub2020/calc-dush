# Привязка к CRM

В верхней части калькулятора раскройте «Связать с CRM» и введите логин и пароль
администратора своей компании на cehcrm.ru. Уже выполненный вход повторять
не нужно: блок покажет название компании и её ID, проверенные через `/api/me/`.
Сверьте их с компанией в модуле «Проекты» CRM.

Калькулятор не принимает произвольный адрес сервера или ID компании от пользователя.
Авторизация и запросы выполняются через собственный `/api/`, пароль не сохраняется.
Сервер CRM определяет компанию по учётной записи. После сохранения КП с контактами
клиента проект появляется в столбце «Заявки» только этой компании. Статус «КП переданы» означает,
что архив успешно синхронизирован; при ошибке она показана в блоке связи.

Очередь отложенных изменений архива разделена по компаниям. При отключении CRM
она сохраняется для прежней компании и не отправляется при входе в другую.
Старая общая очередь переносится только для подтверждённого прежнего аккаунта.
Черновики, впервые созданные без входа, привязываются при первом подключении.

Проверка очередей: `node scripts/test-crm-link.mjs`.
